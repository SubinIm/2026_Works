# Native Host의 포함된 런타임

Windows x64 실행파일은 Python 3.12.14와 PyInstaller 6.21.0으로 빌드했습니다.

- Python의 저작권·라이선스 고지: `licenses/Python-LICENSE.txt`.
- PyInstaller 부트로더의 라이선스와 배포 예외: `licenses/PyInstaller-COPYING.txt`.
- Host의 대응 소스: https://github.com/SubinIm/2026_Works/tree/main/BasicDownloader/native-host/src

FFmpeg, FFprobe, yt-dlp와 Node.js 실행파일은 이 패키지에 포함하지 않습니다.
