    공개 목록 전체와 동일하게 동작하지는 않습니다. 지원되는 일반 요청·요소 숨김 문법만 포함하며, 고급 스크립트 처리와 동영상 내 광고는 다루지 않습니다.

    현재는 확장에 포함된 고정 배포본을 사용합니다. 자동으로 갱신하지 않으며, 새 목록은 로컬에서 다시 빌드하고 확장·웹페이지를 새로고침해야 적용됩니다. 공개 필터를 꺼도 직접 저장한 규칙과 자체 보완 필터는 유지됩니다.

    추적 차단 강화

    선택한 서비스의 로딩과 수집 요청을 차단합니다. 전체·사이트 일시 중지가 우선합니다. 변경 후 웹페이지를 새로고침하세요.

    Google Analytics, Hotjar, Clarity, Matomo와 주요 SNS 픽셀·분석 서비스, 알려진 지문 수집 스크립트를 차단합니다. Google Tag Manager의 일반 컨테이너는 차단하지 않습니다.

    사이트 자체 수집 주소에도 일부 적용됩니다. 로그인·결제 등 정상 기능에 문제가 생기면 현재 사이트 차단을 일시 중지하고 새로고침하세요.

    Sentry·Bugsnag. 사이트의 오류 진단 전송도 중단됩니다. 문제가 생기면 해당 설정을 끌 수 있습니다. 광고를 화면 밖으로 이동하는 기능은 유지됩니다.

    영상 광고 · 지문 보호

    YouTube 페이지의 초기·추가 재생 데이터에서 광고 정보를 제거하고, 광고 재생 중 표시되는 건너뛰기 버튼을 자동으로 누릅니다. Shorts 광고 항목도 처리합니다. 연속 재생에 광고 정보가 필요한 방식에서는 데이터를 보존하고 자동 건너뛰기만 사용하므로 광고가 남을 수 있습니다. 서버에서 본 영상과 합쳐 보내는 광고·삽입 프레임·모든 계정별 동작은 보장하지 않습니다. 재생에 문제가 생기면 끄고 새로고침하세요.

    Google IMA 광고 SDK와 일부 VAST 요청을 차단합니다. YouTube의 재생을 보호하기 위해 해당 사이트는 이 요청 차단에서 제외하며 위의 전용 옵션으로 처리합니다. 광고 SDK에 의존하는 다른 플레이어는 본 영상도 재생되지 않을 수 있으므로 이 설정을 끄거나 해당 사이트 차단을 일시 중지하고 새로고침하세요.

    최상위 페이지의 캔버스 읽기·내보내기와 오디오 샘플에 미세 변화를 추가합니다. 그래픽·음원 편집 결과에 영향을 줄 수 있습니다. 보호 값을 새 페이지마다 바꾸며, 삽입 프레임·Worker는 보호 범위에 포함되지 않습니다.

    각 기능은 기본적으로 꺼져 있으며 독립적으로 적용됩니다. 전체·사이트 일시 중지가 우선합니다. 켜거나 끈 뒤에는 웹페이지를 새로고침해야 완전히 반영됩니다.

    광고 API · 개인정보 거부 신호

    광고·Private State Token API 노출을 줄이고 문서 응답에 제한 정책을 더합니다. Chrome의 전역 개인정보 설정은 바꾸지 않습니다. 토큰 기반 인증 등 일부 기능에 영향을 줄 수 있습니다. 삽입 프레임의 API 노출은 그대로일 수 있으며, 정책은 브라우저가 지원하는 기능에 적용됩니다.

    HTTP 요청에 Sec-GPC: 1을 보내고 최상위 페이지에 navigator.globalPrivacyControl=true를 제공합니다. 서버가 신호를 따르는지는 별개이며 광고·쿠키·동의 창을 자동으로 차단하지 않습니다. 삽입 프레임·Worker의 JS 속성은 변경하지 않습니다.

    각각 기본값은 꺼짐입니다. 전체·사이트 일시 중지가 우선하며 켜거나 끈 뒤에는 웹페이지를 새로고침하세요.
