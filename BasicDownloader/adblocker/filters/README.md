# 공개 필터 데이터

이 폴더는 EasyList와 `FilteringDev/filterslists-KO`의 **Classic for AdGuard** 원문을 개인용 확장 프로그램에서 사용할 수 있는 JSON으로 변환한 결과입니다. 두 목록을 함께 변환하고 함께 켭니다. 서로 다른 목록에 있는 예외와 `$badfilter`를 분리하지 않기 위한 구성입니다.

`manifest.json`에 원본 URL, 원본 버전, 다운로드 시각, SHA-256, 변환기 버전, 실제 규칙 수, 출력 파일 체크섬이 있습니다. `sources/`에는 실제로 변환한 원문이 보관됩니다. 원문을 확장 프로그램에서 실행하거나 원격 JavaScript를 불러오지 않습니다.

## 갱신과 재현

Node.js 22 이상이 필요합니다. 변환기는 개발 도구이며 확장 프로그램 실행에 필요한 의존성이 아닙니다.

```powershell
cd adblocker/tools/filter-builder
pnpm install --frozen-lockfile --ignore-scripts
node build.mjs --offline
```

고정된 `pnpm-lock.yaml`과 패키지 버전으로 설치합니다. `--ignore-scripts`는 의존성 설치 스크립트를 실행하지 않도록 합니다. `node_modules`는 체크인하거나 배포하지 않습니다.

```powershell
# 최신 원본을 다운로드한 뒤 검증·변환
node build.mjs

# 저장된 원본 및 체크섬으로 네트워크 없이 재생성
node build.mjs --offline

# 마지막 정상 교체 직전의 묶음으로 복원
node build.mjs --rollback

# 변환·예외·할당량·트랜잭션 안전성 테스트
node --test tests/*.test.mjs
```

확장 프로그램 폴더의 `npm run filters:update`, `npm run filters:build`도 각각 갱신과 오프라인 재생성을 실행합니다. 실행이 성공한 뒤 `chrome://extensions`에서 확장 프로그램을 새로고침합니다. 빌드 도중에는 확장 프로그램을 새로고침하지 않습니다. 주기적 원격 갱신은 없으며, 위 명령을 실행할 때만 공개 목록 서버에 접속합니다. 한국어 목록은 npm의 최신 패키지 버전을 확인한 다음 그 **버전이 명시된 CDN 주소**에서 받습니다.

다운로드 오류, HTML 응답, 예상보다 작은 원문, 모르는 조건부 문법, 원문 체크섬 불일치, 변환할 수 없는 일반 네트워크 예외, 규칙 할당량 초과가 있으면 새 생성물을 적용하지 않습니다. 변환기의 자동 잘라내기도 실패로 처리합니다. 모든 생성물을 먼저 메모리에서 검증하고 파일마다 원자적으로 교체하며 `manifest.json`을 마지막에 기록합니다. 중간 실패 시 전체 이전 파일을 복원합니다.

동시에 실행된 두 빌드는 `filters/.build.lock`으로 차단합니다. 프로세스가 강제 종료되어 잠금 파일이 남았다면 그 파일에 기록된 PID의 빌드가 끝났는지 확인한 후 잠금 파일 하나만 삭제하고 다시 실행합니다. 다음 실행은 `.pending-build.json`에 남은 이전 파일을 먼저 복구합니다. 정상 교체 후에는 `.rollback/`에 직전 묶음을 보관합니다. 첫 빌드 직후에는 이전 생성물이 없으므로 복원 대상이 없습니다.

## 적용 범위와 예외

- 네트워크는 `block`, `allow`, `allowAllRequests`만 허용합니다. 리디렉션·헤더 수정·응답 변조와 이에만 해당하는 예외는 함께 제외합니다. 스크립틀릿과 절차형 CSS도 실행하지 않습니다.
- 일반 예외는 변환기가 해석한 조건을 유지합니다. 예외를 도메인 전체 허용 같은 다른 의미로 단순화하지 않습니다. 변환할 수 없는 일반 네트워크 예외는 빌드 실패입니다. CSS 예외는 별도 보존합니다.
- 목록 간 `$badfilter` 취소도 함께 적용합니다. 현재 변환기가 완전히 지원하지 않는 `$domain` 범위의 `$badfilter`가 새 원문에 생기면 잘못된 차단을 배포하지 않고 빌드를 실패시킵니다.
- 모든 차단 규칙에서 `main_frame`과 `media`를 제외합니다. 팝업 탐색과 동영상 전용 VAST/VPAID·프리롤·미드롤·포스트롤 패턴도 제외합니다. 주요 동영상 서비스의 요청 목적지/initiator에는 우선순위가 높은 허용 보호 규칙을 둡니다. 알려지지 않은 플레이어와 배너가 광고 인프라를 공유할 수 있어 모든 인스트림 광고를 완벽하게 구별할 수는 없습니다. 동영상 광고 차단 기능을 제공한다는 의미가 아닙니다.
- 공개 필터의 우선순위는 원래 순서와 동률을 보존한 채 1부터 다시 매깁니다. 최대 100,000, 사용자 직접 네트워크 차단 200,000, 사이트/전체 일시정지 1,000,000입니다.
- 최대 100,000개 규칙, 정규식 최대 1,000개를 허용하며 초과하면 실패합니다. 다른 확장 프로그램과 공유하는 Chrome의 남은 정적 규칙 용량은 실제 활성화 때 별도로 확인해야 합니다. `responseHeaders` 조건이 있으므로 Chrome 128 이상이 필요합니다.
- CSS 숨김과 네트워크 차단은 서로 다른 기능입니다. 요소를 숨겼다고 해당 요청까지 차단되는 것은 아닙니다.

## 검토 자료

- `network-source-map.json`: 최종 DNR ID에서 원본 목록·줄 번호·필터 문자열로 가는 전체 매핑. 동영상 보호 규칙은 로컬 정책으로 표시합니다.
- `build-report.json`: 네트워크 제외 항목 전체와 사유, 플랫폼 분기 제외 항목, CSS 지원 범위·제외 사유·보수적으로 확장한 예외.
- `cosmetic.json`: 런타임에서 사용하는 선언형 CSS 선택자와 사이트별 예외. 실행 코드를 포함하지 않습니다.
- `SOURCES_AND_LICENSES.md`: 원본과 변환기 저작자, 라이선스, 수정 내역.

원본 목록이 광고를 빠뜨리거나 사이트 구조가 바뀔 수 있습니다. 업데이트 후에는 네이버·다음·디시인사이드 같은 실제 이용 사이트의 로그인, 검색, 댓글, 정상 이미지, 동영상 재생을 확인하고 문제가 있으면 사이트 일시정지 또는 공개 필터 스위치로 되돌릴 수 있습니다.
