# Paperdesk

Chrome·Edge용 로컬 논문·기술문서 라이브러리. 빌드나 서버 없이 이 폴더를 확장프로그램으로 설치합니다.

## 설치

1. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`로 이동합니다.
2. 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택하고 `reference-manager/dist` 폴더를 지정합니다. 소스를 변경했다면 `node build.mjs`로 이 폴더를 갱신합니다.
4. Paperdesk 아이콘을 툴바에 고정합니다.

## 사용

- 논문·기술문서 웹페이지에서 확장 아이콘을 눌러 추출된 내용을 확인하고 저장합니다.
- **라이브러리 열기**에서 제목을 눌러 서지정보, 태그(쉼표 구분), 컬렉션, 읽기 상태, 메모, 버전과 열람일을 편집합니다.
- **자료 추가**로 수동 등록하거나 PDF를 첨부합니다. PDF당 최대 50 MB이며 첨부 PDF 버튼은 파일을 다운로드합니다.
- 동일 DOI 또는 URL은 중복으로 판단합니다. URL의 추적 매개변수와 fragment는 비교에서 제외됩니다.
- **전체 백업**은 PDF를 포함한 JSON입니다. **백업 가져오기**는 기존 자료를 유지하고 중복 ID·DOI·URL을 건너뜁니다. 가져오기 파일은 최대 250 MB입니다. 대량 PDF 보관 시 이 제한을 고려하세요.
- **검색 결과 BibTeX**는 현재 컬렉션·검색·필터에 보이는 자료를 `@misc` 항목으로 내보냅니다. 저자는 세미콜론으로 구분해서 입력합니다.

## 저장과 권한

자료는 확장프로그램의 IndexedDB에 저장됩니다. 클라우드 업로드, 외부 분석, 자동 동기화가 없습니다. Chrome과 Edge, 서로 다른 프로필의 데이터는 별개입니다. 확장 삭제 또는 브라우저 프로필 삭제로 자료가 사라질 수 있으므로 정기적으로 백업하세요. PDF는 원래 파일 경로와 독립된 복사본입니다.

`activeTab`과 `scripting`은 사용자가 확장 아이콘을 눌렀을 때 현재 페이지의 메타데이터를 읽는 데 사용합니다. `unlimitedStorage`는 PDF를 포함한 로컬 저장을 위한 권한입니다. 참고: https://developer.chrome.com/docs/extensions/develop/concepts/activeTab

## 첫 버전의 범위

사이트가 제공하는 citation/DC/Open Graph 메타데이터를 읽습니다. 정보가 없으면 직접 편집해야 합니다. 내장 PDF 뷰어나 브라우저 내부 페이지는 자동 추출이 제한되며 PDF를 직접 첨부할 수 있습니다. 원문 링크는 해당 페이지를 열며 웹페이지 전체를 오프라인 저장하지 않습니다. PDF 본문 검색·하이라이트, DOI 외부 조회, Word 인용 플러그인, RIS 가져오기, 기기 간 동기화는 포함하지 않습니다.

## 검증

`node --test tests/*.test.js`로 모델 검증을 실행합니다. Windows의 기본 Chrome 설치가 있는 경우 `node tests/browser-smoke.mjs`로 별도 headless 브라우저 프로필에서 IndexedDB 저장, 중복, 편집, 가져오기, 삭제, 메타데이터 추출을 검사합니다. `.test-profile`은 테스트 전용 프로필이며 실제 사용자 프로필과 분리됩니다.

실제 확장 설치 후 웹페이지 수집, 브라우저 재시작 후 데이터 유지, PDF 첨부·다운로드, PDF 포함 백업·복원을 추가 확인하세요. 브라우저 통합 검사는 HTTP에서 라이브러리를 검증하므로 확장 권한과 팝업 자체의 설치 검증을 대체하지 않습니다.
