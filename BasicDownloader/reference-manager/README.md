# Paperdesk

Chrome·Edge용 로컬 연구 자료 라이브러리. PDF·메모·읽기 상태를 내 브라우저에 보관합니다.

## 현재 버전: 0.9.0

- 열린 탭을 주제별로 정리하고, 이미 저장한 탭도 선택하여 수정·보완합니다.
- 논문·기술문서·특허·위키·웹도구·쇼핑·상품정보를 세부 분류합니다.
- 로컬 PDF, 열린 원문, 공개 서지 페이지, Crossref·DataCite 등록정보로 제목·저자·발행일·DOI를 보완합니다. 추출 결과는 검토 후 저장합니다.
- 같은 논문의 PDF 항목은 기존 논문으로 연결합니다. 메모·태그·첨부·읽기 상태·방문 기록을 보존하며, 연결 원본은 기본 목록과 조회 큐에서 숨깁니다.
- 검색·필터·서지 조회 옵션은 새로고침 후에도 유지합니다. 기술문서 조회 체크박스는 처음에는 해제되어 있습니다. **설정 초기화**는 표시·조회 옵션과 폴더 연결·자동 기록을 초기화하고 저장 자료를 보존합니다.
- Chrome·Edge에서 같은 로컬 폴더를 선택하면 폴더 자료가 현재 목록에 함께 표시됩니다. 동일 문서의 브라우저별 메모와 읽기 상태를 구분합니다. 폴더 자료는 가져오기 전까지 읽기 전용입니다.
- 팝업과 사이드바에서 수집하며, 도구모음·페이지 탭에 P 로고를 표시합니다.

## GitHub에서 설치하기

Node.js 22.13 이상을 준비하고 다음 명령을 실행합니다. Windows에서는 `npm` 대신 `npm.cmd`를 사용할 수 있습니다.

```sh
git clone --filter=blob:none --sparse https://github.com/SubinIm/2026_Works.git
cd 2026_Works
git sparse-checkout set BasicDownloader/reference-manager
cd BasicDownloader/reference-manager
npm ci --ignore-scripts
npm test
npm run build
```

Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 이 폴더의 `dist`를 선택합니다. 소스가 아니라 빌드된 `dist`를 로드해야 PDF 분석에 필요한 파일도 포함됩니다. Chrome 116 이상과 호환 Edge의 데스크톱 환경을 대상으로 합니다. 별도의 네이티브 도우미는 필요하지 않습니다.

기존 설치를 업데이트할 때는 **전체 백업 (PDF 포함)**을 먼저 저장합니다. 소스 폴더에서 `git pull --ff-only`, `npm ci --ignore-scripts`, `npm test`, `npm run build`를 실행한 뒤 기존 확장의 새로고침 버튼을 누르고 Paperdesk 페이지를 다시 엽니다. 별도 설치 폴더에서 로드한 경우에는 새 `dist`의 내용을 그 폴더에 복사한 뒤 새로고침합니다. 확장 ID와 자료를 유지하려면 기존 설치 폴더를 계속 사용합니다.

GitHub에는 소스·테스트·아이콘·의존성 잠금 파일을 공유합니다. `dist`와 `node_modules`는 로컬에서 만들며, 개인 라이브러리·메모·백업 PDF는 포함하지 않습니다. Chrome Web Store 게시는 별도이며 현재는 압축해제 설치 방식입니다.

## 0.5.0 — 문서 서지정보·특허·위키

- 종류에 **기술문서 (특허)**, **위키**, **도서**를 추가했습니다. Google Patents·특허 PDF, Wikipedia·나무위키와 위키 주소, Artech House 도서를 구분합니다. 주제 컬렉션에는 **탐지·추적**을 추가했습니다. 자료 종류와 연구 주제는 따로 저장합니다.
- 팝업에서 제목·저자·발행일·DOI·원문/PDF URL을 확인하고 수정합니다. 기본 PDF 뷰어 등 자동 추출이 제한되면 **문서 서지정보 읽기**를 누릅니다. DBpia 뷰어는 실제 제목과 공개 서지 페이지를 사용하고, arXiv PDF는 서지 페이지, 특허 PDF는 공개 특허 페이지로 대응합니다.
- **열린 탭 자동 정리 → 선택 탭 서지정보 읽기**는 해당 자료의 사이트만 요청합니다. citation, Dublin Core, 논문 JSON-LD와 공개 서지 페이지에서 복수 저자·발행일·발행처·DOI를 읽습니다. 학술발표회 초록집을 학회 논문으로, 특허의 발명자와 공개일을 저자·발행일로 표시합니다. 기관명·특허 출원인·출원일·참고문헌 DOI를 논문 저자·DOI와 구별합니다.
- 이미 저장한 자료도 각 항목의 **이 탭 서지정보 읽기**에서 보완안을 검토하고 **저장·보완**합니다. 메모·읽기 상태·버전·첨부 PDF·로컬 원본은 보존합니다. 검토 중 변경되거나 삭제된 자료와 다른 항목의 DOI가 겹치는 변경은 건너뜁니다.
- DOI가 확인되면 **DOI 원문 ↗** 링크를 표시합니다. DOI가 없거나 충돌하면 추측하지 않습니다. DOI 링크와 해당 서지 페이지를 별도로 열 수 있습니다. 원문에 DOI가 없는 학회 초록집·특허·위키도 저장할 수 있습니다.
- PDF에는 잘못 남은 `Paper Title`·IEEE 양식 정보가 있을 수 있습니다. 이런 제목은 제외하고 저장소 표지의 APA 인용 또는 앞 두 페이지의 제목을 사용합니다. DOI와 저자가 확인되지 않은 스캔·보호 문서는 수동 입력/파일 선택이 필요합니다.
- 공개 서지 페이지 읽기는 쿠키를 보내지 않으며 리다이렉트·임시 인증 주소를 거절하고 2 MB/12초로 제한합니다. 공개 PDF의 정보 분석은 기존 50 MB 제한을 사용합니다. 선택적 사이트 권한은 **문서·PDF 사이트 접근 해제**에서 취소할 수 있습니다. 백그라운드 탐색이나 로그인/유료 PDF 우회는 없습니다.

48개 자동 검사와 Chrome·Edge의 열린 SAGE·DBpia·arXiv·특허 공개 서지 페이지, TU Delft 공개 PDF 분석을 확인했습니다. 개발 화면에서는 실제 DOMParser·IndexedDB를 사용하고 탭·권한·서지 응답은 예시 API로 제공합니다. 실제 설치 권한 창과 라이브러리 저장은 확장 새로고침 후 사용자가 확인해야 합니다.

## 0.4.0 — Edge와 공유 폴더

Windows 데스크톱 Chrome와 Edge에 같은 `dist`를 설치합니다. API 호출은 두 브라우저에서 지원되는 `chrome.*`를 사용하며 추가 확장 권한이나 네이티브 도우미 설치는 없습니다.

1. Edge의 `edge://extensions`에서 개발자 모드를 켜고 **압축 풀린 파일 로드**로 기존 설치의 `dist` 폴더를 선택합니다. 이미 설치했다면 해당 Paperdesk를 새로고침합니다. Chrome도 기존 Paperdesk를 새로고침합니다.
2. 각 브라우저에서 라이브러리를 열고 **폴더 선택**으로 같은 공유 폴더를 지정합니다. 폴더 권한 창을 허용하고 **지금 폴더에 저장**을 누릅니다.
3. **폴더 자료 함께 보기**는 각 브라우저·설치의 최신 저장본을 모읍니다. 같은 ID·DOI·URL의 자료는 한 묶음으로 표시하며, 브라우저 이름·설치 식별자·저장 시각·메모·읽기 상태는 각각 보여줍니다. 브라우저 필터와 검색을 지원하고 **저장본 새로 고침**으로 다시 읽습니다. 이 보기는 현재 브라우저 DB를 바꾸지 않습니다.
4. **폴더 저장본 가져오기**에서는 브라우저별 최신 저장본을 선택합니다. 새 자료만 추가하고 기존 ID·DOI·URL에 해당하는 메모·읽기 상태·첨부는 덮어쓰지 않습니다.
5. **라이브러리가 열린 동안 자동 저장**을 켜면 자료 변경 뒤 약 1.2초 후 새 저장본을 만듭니다. 팝업 등 같은 확장의 다른 화면 변경도 전달됩니다. 라이브러리가 닫힌 동안에는 저장하지 않으며, 다음에 열 때 최신 자료를 내보냅니다. 폴더 권한이 만료되면 **지금 폴더에 저장**에서 다시 허용합니다. 닫기 전에 저장 완료 메시지를 확인하세요.

선택한 폴더 아래에는 `Paperdesk/snapshots/chrome-<설치ID>/…json`, `Paperdesk/snapshots/edge-<설치ID>/…json`과 `Paperdesk/pdfs/<SHA256>.pdf`를 만듭니다. 서지정보와 PDF를 분리하고 동일한 PDF는 재사용합니다. PDF가 모두 저장된 뒤 JSON을 기록하며, 중단된 JSON 대신 이전 완성본을 찾습니다. 저장본에는 메모·DOI·분류·파일 이름·로컬 원본 경로도 포함됩니다. 원래 PDF 경로만 있는 항목의 파일 내용은 먼저 직접 첨부해야 합니다.

브라우저 간 자동 변경 덮어쓰기·삭제 전파와 백그라운드 양방향 동기화는 지원하지 않습니다. 저장본과 PDF는 자동 삭제하지 않습니다. 오래된 저장본은 원본 폴더를 먼저 복사한 뒤 따로 보관할 수 있습니다. 단일 저장본은 10,000개 자료·25 MB 서지정보, 각 PDF는 50 MB, 한 번의 PDF 포함 가져오기는 250 MB까지 지원합니다. 최신 서지정보를 함께 볼 때에는 PDF를 메모리에 읽지 않고, 첨부 다운로드 때 크기와 SHA256을 검증합니다.

폴더 설정은 별도 IndexedDB `paperdesk-folder-settings`에 보관합니다. 기존 개인 라이브러리 DB와 JSON 백업 버전은 유지합니다. 폴더 연결 해제는 자동 저장과 기억한 핸들을 해제하며 기존 파일을 지우지 않습니다.

공식 자료: [Edge 확장 포팅](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/port-chrome-extension), [File System Access API](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access).
## 0.3.0 — 저장 탭 닫기·세부 분류·PDF 연결

- **저장한 탭 닫기**: 저장된 자료와 대응하는 현재 탭을 선택해서 닫습니다. 닫기 직전에 자료 존재·주소·이동 여부를 다시 확인합니다. 고정·시크릿·소리 재생 중인 탭은 보호합니다. 라이브러리 자료는 삭제하지 않습니다. Chrome의 `Ctrl+Shift+T`로 닫은 탭을 복원할 수 있습니다.
- **자료 종류**: 저널 논문, 학회 논문, 프리프린트, 학위논문, 규정·표준, 기술·연구보고서, 매뉴얼·안내, 웹도구, 데이터·지도 자료, 웹페이지·기사. 기존 논문·기술문서 값은 세부 확인용으로 유지합니다. Windy는 **웹도구**, 주제 컬렉션은 **GIS·환경**으로 제안합니다.
- **PDF 파일 연결·서지정보 찾기**: 여러 PDF를 선택하여 메타데이터와 앞 3페이지의 텍스트·링크에서 제목, DOI, 저자, 발행연도, 저널·학술대회명과 분류를 제안합니다. DOI가 없거나 여러 개면 임의로 선택하지 않습니다. 파일당 최대 50 MB이며 스캔 PDF의 OCR은 없습니다.
- **기존 자료에 할당**: DOI, 정규화한 정확한 제목, 유일한 파일명 순서로 대응 자료를 제안합니다. 파일명만 일치하면 검토가 필요합니다. DOI가 다른 자료에는 연결하지 않습니다. 기존 메모·읽기 상태·버전·첨부를 유지하고 빈 서지정보를 채웁니다. 기존 첨부를 덮어쓰지 않습니다. 검토 중 수정된 연결 대상은 건너뜁니다.
- 로컬 PDF 원본 항목은 기존 자료에 연결하여 보존합니다. **연결된 PDF 원본 항목 포함**을 켜서 원본 메모와 첨부를 봅니다. 원본 경로는 중복 수집과 저장 탭 판별에 계속 사용합니다.
- 온라인 PDF 카드의 **PDF 정보 찾기**는 해당 사이트의 선택적 접근 권한을 요청합니다. 파일 선택에는 사이트 권한이 필요 없습니다. 로그인 쿠키를 보내지 않고 인증 주소·리다이렉트·HTML 뷰어를 자동 분석하지 않습니다. 실패하면 PDF를 내려받아 선택하세요. **PDF 사이트 접근 해제**로 부여한 사이트 권한을 취소합니다.

## 연구 탭 자동 정리

**열린 탭 자동 정리**는 각 브라우저의 같은 프로필의 일반 창 탭을 검토 목록으로 수집합니다. 최초 클릭 시 선택적 `tabs` 권한을 요청하며 **탭 접근 해제**로 취소합니다. 백그라운드 감시나 자동 탭 닫기는 없습니다.

주제 컬렉션은 안전제어·도달가능성, 인증·규정, 비행절차·공항, 추진·모터, 공역·UTM·위험도, GIS·환경입니다. **기존 자료 분류 제안**은 종류를 세분화하고 비어 있거나 분류 검토인 컬렉션을 채웁니다. 사용자가 정한 컬렉션은 유지합니다. 분류 규칙은 추정이므로 저장 전에 수정할 수 있습니다.

DOI, IEEE 문서번호, ScienceDirect PII가 같으면 원문·PDF 탭을 묶습니다. 인증 토큰을 포함한 임시 주소는 저장하지 않습니다. 검색·로그인·알려진 채팅 서비스는 제외하며 일반 페이지는 기본 선택하지 않습니다. 모든 개인 사이트를 식별할 수는 없으므로 후보를 검토해주세요.

로컬 PDF 탭 수집은 제목·파일명·경로만 저장합니다. 파일 내용은 **PDF 파일 연결·서지정보 찾기**에서 파일을 선택해야 읽습니다. Chrome의 파일 접근 권한은 자동 변경하지 않습니다.

## 설치·기존 설치 업데이트

1. `npm ci --ignore-scripts`로 의존성을 설치합니다. Node.js 22.13 이상 또는 24 이상을 사용합니다.
2. `npm test`로 검사하고 `npm run build`로 `dist`를 만듭니다.
3. 신규 설치는 Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `dist`를 지정합니다.
4. 기존 설치는 기존 폴더에 빌드를 적용하고 **기존 Paperdesk의 새로고침 버튼**을 누릅니다. 라이브러리 탭도 다시 열거나 새로고침합니다.

기존 설치 폴더 이름이 이전 버전을 포함하더라도 실제 버전은 `manifest.json`의 0.9.0입니다. 소스 업데이트는 브라우저 설치를 자동 갱신하지 않습니다. 기존 경로에 빌드 결과를 적용하고 확장을 새로고침하세요.

## 저장·백업·인용

IndexedDB `paperdesk` 버전 1과 JSON 백업 버전 1을 유지하고 세부 종류·발행처·PDF 연결 정보를 보존합니다. 구버전으로 다운그레이드하면 새 분류와 연결 표시를 해석하지 못할 수 있습니다.

**전체 백업 (PDF 포함)**과 **백업 가져오기**를 사용합니다. 중복 ID·DOI·URL은 건너뛰고 연결 원본은 유지합니다. 가져오기 한도는 250 MB입니다. 직접 선택하지 않은 로컬 PDF는 경로만 백업됩니다. 브라우저·프로필별 데이터는 별개이며 확장 삭제·프로필 삭제 전에 백업하세요.

BibTeX는 저널을 `@article`, 학회 논문을 `@inproceedings`로 내보내고 발행처를 포함합니다. 저자는 세미콜론으로 구분합니다. 팝업은 페이지의 citation/DC/Open Graph 정보를 사용합니다.

## 권한·개인정보

필수 권한은 `activeTab`, `scripting`, `unlimitedStorage`, `sidePanel`입니다. `tabs`와 HTTP/HTTPS 사이트 접근은 선택적입니다. 실행 중에는 사용자가 읽는 문서·서지 페이지·PDF의 해당 origin만 요청합니다. 부여 여부는 브라우저 확인 창에서 사용자가 정합니다. 사이트 접근 해제와 탭 접근 해제는 독립적입니다.

AI API, 외부 분석 업로드, 텔레메트리와 클라우드 동기화는 없습니다. 명시적으로 서지정보 찾기를 실행하면 공개 DOI를 Crossref·DataCite에, 논문 제목을 Crossref에 조회할 수 있습니다. 로컬 PDF·경로·메모는 전송하지 않습니다. PDF 분석은 번들에 포함된 공식 PDF.js와 로컬 worker를 사용합니다. 사용자 요청에 따른 온라인 PDF 다운로드·원문 열기는 해당 사이트에 연결합니다. 라이선스는 `dist/vendor/LICENSE.pdfjs`에 포함합니다.

공식 자료: [Chrome tabs.remove](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-remove), [선택적 권한](https://developer.chrome.com/docs/extensions/reference/api/permissions), [PDF.js](https://mozilla.github.io/pdf.js/examples/).

## 쇼핑·기타 정리 (0.5.1)

라이브러리의 **쇼핑·기타 분류 제안**은 저장된 제목·원문 주소·서지정보만으로 쇼핑몰, BMW 320d 같은 차량 페이지와 부품 카탈로그를 찾아 종류와 컬렉션을 **기타**로 제안합니다. 기존 컬렉션이 무엇이었는지와 판별 근거를 검토하고 선택 항목만 적용하세요. 자동 연구 주제 태그는 제거하고 개인 태그·메모·첨부 PDF·읽기 상태는 보존합니다. DOI, 학술 사이트, 저자·발행처, 학술 제목 등 연구 근거가 있는 자료는 보호합니다. 휴리스틱이므로 경계 사례는 자료 편집에서 조정할 수 있습니다.

**쇼핑·기타 제외하고 보기**는 아직 분류를 적용하지 않은 쇼핑 후보까지 숨깁니다. 체크를 해제하면 다시 보이며, 자료를 삭제하거나 변경하지 않습니다. 같은 필터를 Chrome·Edge **폴더 자료 함께 보기**에서도 사용할 수 있습니다. **종류 → 기타** 또는 **기타 컬렉션**은 적용한 항목만 표시합니다.

0.5.2: 파츠119(parts119.com)와 수입차·자동차 부품 구매·조회 제목도 기타로 제안합니다. 이전에 기술문서로 저장된 항목은 쇼핑·기타 분류 제안에서 선택 적용하면 갱신됩니다.

## 기존 자료 조회·계층 분류·방문 기록 (0.6.0)

자료 카드의 **서지정보 찾기** 또는 **검색 결과 서지정보 찾기**에서 이미 분류한 자료를 다시 조회할 수 있습니다. 선택 자료의 사이트 접근을 허용한 뒤 제목·저자·발행일·DOI 보완안을 확인하고 저장하세요. 현재 대응 탭, 저장된 원문 페이지, 온라인 PDF와 첨부 PDF를 사용하며 기존 컬렉션·메모·읽기 상태·첨부를 유지합니다. 유료·로그인 페이지, DOI 리디렉션만 있는 주소 또는 정보가 없는 문서는 자동 수집이 실패할 수 있습니다. 이때 원문 주소나 PDF를 직접 지정하세요.

**전체 → 논문 / 기술문서 / 웹 자료 / 도서 / 기타 → 세부분류**로 필터링합니다. **세부확인 항목**은 논문(세부 확인)과 기술문서(세부 확인)을 모아 보여줍니다. 같은 필터를 Chrome·Edge 폴더 통합 보기에서도 사용합니다.

문서 열기·서지조회 횟수와 최근 시각을 표시하고 **방문 기록**에서 문서 SHA-256 지문과 최근 200개 동작을 봅니다. 횟수는 전체 누적이며 조회 실패도 허용된 조회 시도로 기록합니다. **저장 문서 방문 자동 기록**을 켜면 활성화·로드된 저장 문서 방문도 기록합니다. 초기값은 꺼짐이고 기존 tabs 권한을 요청합니다. 시크릿·미저장·대기 중인 탭은 기록하지 않습니다. 활성화와 로드의 5초 내 쌍은 중복 제외하며, 자동 방문과 문서 열기는 서로 별도 지표입니다. 기록은 이 버전 사용 이후부터 쌓이고 과거 기록을 복원하지 않습니다. 문서별 기록은 백업과 폴더 저장본에 포함되며 브라우저별 기록을 합산하거나 덮어쓰지 않습니다. 장치 지문·원격 추적은 사용하지 않습니다.


## 로컬 PDF 우선 조회·탐색 레퍼런스·상품 분류 (0.6.1)

**서지정보 찾기**는 연결·첨부된 PDF를 우선 분석합니다. 이때 사이트·탭 권한이나 네트워크가 필요하지 않습니다. 파일 경로만 있는 자료는 **로컬 PDF 선택·서지정보 확인**에서 파일을 한 번 선택하고 추출 결과를 검토해 저장하세요. 선택한 PDF는 기존 첨부가 없으면 연결되며 다음 조회부터 재사용됩니다. 기존 첨부가 있으면 보존합니다. 논문 제목은 파일명 대신 PDF 서지 제목·인용 표지 또는 첫 페이지 제목을 사용하고, 추정 제목은 검토 표시합니다. 스캔 PDF는 OCR 없이 자동 추출할 수 없습니다.

그림·표 뷰어의 `Figure 6 | 논문 제목` 형식은 논문 제목과 **탐색 레퍼런스**로 나눕니다. 기존 자료는 서지정보 보완을 저장할 때 이전 그림·표 제목도 보존합니다. 서지정보 수집 시 선택 글귀와 주소 앵커에 대응하는 대목을 별도 저장합니다. 자동 방문 기록은 글귀를 새로 읽지 않습니다. 카드의 탐색 레퍼런스에서 대목 주소를 열 수 있고, 검색·백업·브라우저별 폴더 저장본에도 포함됩니다. 최신 100개 문맥을 보관하고 동일 글귀·주소는 중복 제외합니다.

**쇼핑·상품정보 → 쇼핑 / 상품정보**를 추가했습니다. Cults의 개별 3D 모델, 일반 쇼핑몰 상품 페이지는 상품정보로, 장바구니·구매 페이지는 쇼핑으로 제안합니다. 웹도구로 잘못 저장한 항목은 기존 자료 분류 제안 또는 쇼핑·기타 분류 제안에서 검토해 적용하세요. 이전 Parts119·차량 부품 카탈로그의 기타 분류는 유지합니다.

## 서지정보 탐색 큐·누락 보완 (0.7.0)
- 기본 큐: 논문·기술문서 중 서지정보 미확인 자료. 완성된 기존 서지정보 또는 저장한 확인 결과는 제외하며, 확인 자료·다른 종류는 상단 옵션으로 포함합니다. 개별 자료의 찾기는 명시적 재조회입니다.
- 논문은 문서 제목·저자·발행일, 기술문서는 문서 제목·저자/발행기관·발행일/버전을 기준으로 누락을 표시합니다. DOI가 없는 학회 논문도 완료할 수 있습니다. 직접 확인한 자료는 수동 확인 완료를 표시할 수 있습니다.
- 추출한 정보는 저장·보완한 이후 확인 상태를 보존합니다. 추정 PDF 제목·DOI 충돌은 계속 검토 대상으로 남습니다. 내용이 바뀌면 이전 확인 상태를 그대로 신뢰하지 않습니다.
- 로컬 PDF → 열린 원문/공개 원문·PDF 순으로 확인합니다. 부분 HTML에서도 온라인 PDF 보완을 시도합니다. 로컬 PDF가 부족하면 원문 탭 열기 → 열린 원문 탭 읽기로 웹 보완이 가능합니다.
- DOI 보완 버튼은 선택한 DOI만 Crossref 공개 API로 전송하며, 같은 DOI의 제목·저자·발행일·저널 및 종류를 검토안으로 제시합니다. 미등록 DOI는 원문·Scholar로 확인하세요.
- Scholar 검색은 제목 또는 DOI만 전송합니다. 결과 원문 URL을 수동 입력하고 탭을 열어 읽습니다. 검색 결과·로그인·CAPTCHA·유료 접근은 자동 처리하지 않습니다. 사이트 권한은 클릭 시 해당 출처만 요청합니다.
- 접속 오류 원인을 안내하고 수동 입력을 활성화할 수 있습니다. 사이트 권한 거절 시 같은 큐의 로컬 PDF 처리는 계속합니다.
- 기본 탐색은 원문/로컬 PDF에서 정보가 부족하거나 읽기에 실패하면 알려진 DOI로 허용된 Crossref 등록정보를 자동 보완합니다. 웹 권한을 거절한 혼합 큐에서는 로컬 PDF만 계속 분석합니다.

## IEEE 열린 원문 수집·실패 진단 (0.7.1)

IEEE Xplore의 화면에 표시된 논문 제목, 문서 헤더 저자, DOI, 저널·학술대회명과 발행일을 읽습니다. citation 메타태그가 없는 동적 화면도 처리합니다. 학회 개최일만 확인되면 연도를 사용하며 Date Added는 발행일로 사용하지 않습니다. 문서 식별자가 다른 PDF 링크와 참고문헌 저자·DOI는 제외합니다. 충분한 서지정보를 열린 탭에서 읽으면 백그라운드 HTML·PDF 요청을 추가하지 않습니다.

조회가 실패하면 열린 탭 권한·로딩·주소 변경, 화면의 서지정보 부재·접속 차단, 공개 원문·온라인 PDF 응답을 단계별로 표시합니다. 원문 화면 자체가 차단되면 DOI 조회, Scholar 검색 또는 로컬 PDF 선택이 필요합니다. Scholar에는 뷰어 주소·PDF 파일명을 검색어로 보내지 않고 제목이나 DOI를 요구합니다. 기존 undefined/null 서지 값은 빈 항목으로 검토하며 개인 메모는 유지합니다.

PDF.js의 잘못된 선택 메타데이터·TrueType 힌팅 경고만으로 사이트 차단이나 서지정보 추출 실패라고 판단하지 않습니다. 본 수정은 PDF.js 경고를 숨기거나 공급업체 코드를 변경하지 않습니다. 기존 검토 중인 보완안을 먼저 저장한 뒤 확장을 다시 로드하고 Paperdesk 탭을 새로 여세요.

## 파일명·제목 보완, 조회 제외, 팝업·사이드바 (0.8.0)

Nature의 s41598/srep, 지원하는 Frontiers 파일 식별자를 DOI 후보로 변환한 뒤 실제 Crossref 등록 DOI를 확인합니다. 파일명의 연도는 발행일로 추정하지 않습니다. 예시 s41598-025-32450-8은 등록 발행일 2026-01-19를 사용합니다. 원문 URL이 비어 있거나 PDF 주소만 있으면 검증된 출판사 원문 링크와 PDF 링크를 채우며 기존 첨부는 유지합니다.

DOI가 없는 논문은 공개 등록정보에서 제목으로 검색합니다. 정확한 제목의 단일 일치와 기존 저자·연도의 일치 여부를 확인하고, 모호하거나 비슷한 제목은 후보 선택으로 남깁니다. 제목·DOI만 요청한 Crossref 사이트로 전송합니다. Google Scholar 버튼은 식별자 파일명도 DOI 검색으로 연결하며 검색 결과를 자동으로 긁지 않습니다.

기존 자료 서지정보 찾기 상단에서 논문·기술문서 세부분류를 각각 선택합니다. 이미 확인한 자료, 논문·기술문서 외 자료, PDF·DOI 없는 기술문서 안내 페이지, 서지 찾기 제외 설정 자료는 기본 제외합니다. 각 옵션을 켜면 선택적으로 조회합니다. 자료의 서지 찾기 제외 체크박스는 즉시 저장하며 상단 제외 자료 포함에서 해제할 수 있습니다. 제외는 삭제가 아닙니다.

저장된 페이지는 팝업에서 기존 제목·메모 등의 내용을 보존한 보완안을 불러오며 이 자료 바로 보완·저장으로 갱신할 수 있습니다. 라이브러리의 전체 열린 탭 정리를 거칠 필요가 없습니다. 사이드바로 이어서 작업 버튼은 입력을 로컬 임시 저장하고 같은 창의 사이드바로 넘깁니다. 다른 탭으로 이동해도 기존 입력을 덮어쓰지 않으며 현재 탭 불러오기로 전환합니다. 탭별 임시 입력을 분리하고 저장하면 해당 입력을 삭제합니다. 사이드바를 처음 쓰면 tabs 접근을, 문서를 읽으면 해당 사이트 접근을 요청합니다. Chrome 116 이상 및 대응 Edge에서 사용하며 미지원 브라우저에서는 기존 팝업을 유지합니다.

갱신 전에 현재 검토 중인 보완안을 먼저 저장하세요. 설치본 소스만 갱신하며 브라우저 자료 DB, 열린 탭, Chrome·Edge 폴더 저장본은 자동 변경하지 않습니다. 두 브라우저 확장 관리 화면에서 다시 로드한 후 사용합니다.
