기본 파일명과 자동 확인

제목 사용을 끄거나 제목을 찾지 못했을 때 쓰는 이름입니다. 각 후보에서도 수정할 수 있습니다. 이미 저장한 파일명은 바뀌지 않습니다.

두 옵션은 기본 꺼짐입니다. 전체 확인은 첫 성공에서 멈추지 않고 다시 Probe하며 쿠키를 보내지 않습니다. 자동 다운로드가 음성 없음으로 실패하면 해당 후보를 제외하고 계속 확인합니다. 후보 초기화/페이지 이동 중에는 자동 다운로드하지 않습니다. 중복 파일은 기존 확인 절차를 유지합니다.

기본 꺼짐. 켜면 새 HTTP(S) 후보를 순서대로 확인합니다(다운로드는 시작하지 않음). 쿠키는 보내지 않습니다. 실패 시 반복하지 않으므로 인증이 필요한 후보는 직접 Probe하세요.

다운로드

YouTube 보조 엔진 (선택)

별도 YouTube 버튼으로 사용합니다. 브라우저 쿠키는 읽거나 보내지 않습니다. 실행 파일은 자동 설치·업데이트하지 않으며 DRM·유료 접근 제한은 우회하지 않습니다. 현재 일반 VOD만 지원합니다.

화면과 파일명

{title}: 제목 · {quality}: Probe로 확인한 해상도 · {date}: 오늘 날짜. 확인하지 못한 품질은 임의로 만들지 않습니다. 직접 편집한 파일명은 자동으로 덮어쓰지 않습니다.

알림은 기본 꺼짐입니다. 알림에 제목·URL은 노출하지 않습니다. 목록에서 제거해도 영상 파일은 삭제되지 않습니다.

Native Host 설치

확장을 unpacked로 로드한 뒤 chrome://extensions에서 확장 ID를 복사하고 등록하세요.

.\scripts\install-host.ps1 -ExtensionId <ID> -ExecutablePath <검증한 stream_host.exe 경로>
