# 2026 Works

개인용 브라우저 확장프로그램 모음입니다.

| 확장프로그램 | 기능 | 버전 |
| --- | --- | --- |
| Personal Stream Downloader | 비 DRM 영상 스트림 탐지와 로컬 다운로드 | 0.3.0 |
| Basic Banner Blocker | 광고 요청·배너 차단, 사이트별 규칙 | 0.10.2 |
| Paperdesk | 논문·기술문서와 PDF 로컬 관리 | 0.1.0 |

**다른 PC에서 설치:** [설치용 ZIP과 한국어 안내](BasicDownloader/docs/SHARING.md)를 확인하세요.

소스와 개발 문서는 [BasicDownloader](BasicDownloader)에 있습니다. 설치용 ZIP에는 빌드한 확장 파일을 포함하며, 다운로드 도구에는 Windows x64 Native Host도 포함합니다. FFmpeg/FFprobe는 별도로 준비해야 합니다.

각 PC에서 확장프로그램을 직접 설치합니다. 설정과 자료는 각 확장프로그램의 백업·가져오기로 옮깁니다.
